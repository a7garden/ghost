# ADR 002 — LocalJudge is an advisory adapter

Start with a trait and mock that chooses only from explicitly allowed candidates, or abstains. Routing and task allocation recommendations cannot approve tools, override policy or authorize finance.

Laya English 421M and multilingual 322M are candidates, not selected production engines. Delegated research records the creator's warning about overconfident probabilities and unreliable act_probability. Korean data validation, calibration and abstention tests are mandatory before selection. No model downloads or resident loading in this unit.

A strict single executable may require a statically embedded ONNX runtime; cross-platform feasibility and licenses require separate evidence. Python/MLX daemons are not a hidden mandatory dependency. Candidate evaluation and native embedding are backlog.
