# Ghost의 목표와 현재 범위

제품 목표와 과업 순서의 정본이다. 구조는 [architecture](architecture.md), 운영은 [local-operations](local-operations.md)를 따른다.

**일을 맡기면 대화와 책임이 유지되고, 필요한 협업을 거쳐 확인 가능한 결과로 돌아온다.** 사용자는 담당자를 중계하거나 내부 실행기를 관리하지 않는다. 기본 Ghost에게 시작하거나 원하는 Ghost에게 직접 맡긴다. 모든 Ghost는 같은 종류의 지속형 봇이며 도구 권한은 각자 설정한다. 메인 Ghost만 직접 대화에서 다른 Ghost의 설정을 바꿀 수 있고, 메인 지정과 자기 자신의 설정 변경은 소유자에게 남는다.

모델은 등록된 외부 제공자로 실행한다. 로컬 모델은 고려하지 않는다. 대화별 개인정보 등급은 없고, 자격이 있는 제공자는 모든 대화와 Ghost의 모든 도구를 쓴다(2026-11-07 소유자 결정).

## 핵심 사용자 흐름

1. 대화에서 일을 맡기고 목표·완료 조건을 확인한다. 일반 대화나 아이디어를 자동으로 맡긴 일로 만들지 않는다.
2. 담당 Ghost가 직접 처리하거나 다른 Ghost에게 위임한다(하위 맡긴 일). 진행·대기·막힘·결정 대기를 추적한다.
3. 사용자는 **맡긴 일**에서 상태와 결과를 확인하고 수정·취소·재개한다.
4. 산출물은 확인 규칙, 검토자, 또는 사용자 수용으로 판정한다. 완료 주장만으로 수용하지 않는다.
5. 앱 종료·Host 재시작 뒤에도 같은 대화·맡긴 일로 돌아온다. 결과가 불명확한 효과는 사용자가 대사한 뒤 이어가며 다시 실행하지 않는다.
6. Ghost별 **자동 활동**을 승인하면 예약·PR·메일 변화를 Host가 감지해 같은 맡긴 일 경로로 실행한다. 도구·실행 환경·일일/동시 한도·다음 점검·답글 정책을 정하고, 실행 기록에서 멈추거나 다시 설정한다. 상시 LLM 사고 루프는 두지 않는다.

## 책임 경계

| 구성 | 책임 |
| --- | --- |
| Ghost | 정체성·페르소나·모델·도구·기억·문서 권한. PC 직접 실행 권한은 소유자가 별도로 부여 |
| Host (`apps/ghost-host`) | 원장·Pi Durable·도구·실행 환경·자동 활동 감지와 한도·API. 상태 루트의 단일 writer |
| Oxibrain | 출처가 있는 기억. Host 원장이나 사용자 원문을 대체하지 않음 |
| 문서 평면 | PDC 2 Space. PDC 1 읽기 호환, 승인 없는 일괄 변환 금지 ([PDC 채택](pdc-adoption.md)) |
| infra | 프로젝트 간 운영·복구·자원 조정 |

## 접점

- Mac 앱과 웹 UI는 Host가 직접 제공한다. iPhone은 같은 웹 UI를 페어링한 기기 토큰으로 그대로 사용하며 소유자와 동등한 권한을 가진다(2026-11-09 소유자 결정). 기기 관리만 소유자 영역이다: 페어링 시작·기기 이름 변경·다른 기기 해제는 소유자만, 기기 자신의 해제는 가능하다.
- 음성, 닫힌 앱 알림의 실물 수용은 후속 범위다.

## 유지·제외·후속

| 분류 | 내용 |
| --- | --- |
| 유지 | 맡긴 일 트리·검증·수정·취소·재개·시간 제한·알림, Ghost 간 위임과 부모 질문, 예약 wake와 승인된 자동 활동(예약·PR·메일·다음 점검), 작업별 컨테이너/명시적 PC 실행, Mac/iPhone, 기억·문서 Space·웹 조사, 승인형 Host 브라우저·금고, 스킬·대체 모델, Mac 상주 점검·승인형 명령 |
| 제외 | 개인 캘린더·할 일 앱, planner·CalDAV·Google 동기화, 별도 OMP/LLM 작업자, 모델 주도 봇 후보/평가 파이프라인, 외부 연동 제안 화면 |

## 먼저 마무리할 흐름

| 과업 | 완료 조건 |
| --- | --- |
| 운영 전환 | 2026-11-07 완료. Bun Host·Mac 앱 설치, 이전 상태 가져오기, 공개 대화의 실제 응답과 Apple container 업무 수용 확인. [현재 설치와 되돌리기](local-operations.md#현재-설치-2026-11-09) |
| 실제 iPhone | 페어링한 기기의 웹 UI로 요청→위임→결정→결과 회수, 재연결 후 같은 맡긴 일, 금고 보안 양식 답변, 기기 스스로의 해제와 그 토큰 거절, 그리고 페어링 시작·기기 변경·다른 기기 해제의 거절을 확인한다. Ghost별 기기 범위는 2026-11-08 소유자 결정으로 제거했고, 2026-11-09부터 기기는 소유자와 동등하다(기기 관리 제외). |
| 장기 실행 | 2026-11-08 격리된 실제 모델·Apple container 업무로 실행 중 `SIGKILL`→효과 대사→완료(append 1회), 취소→재시작 후 취소 유지·컨테이너 해제, 실패→동일 맡긴 일 재개→완료를 확인했다. 설치판의 실제 장기 업무 수용은 이 격리 검증과 구분한다. |
| 자동 활동·PC 실행 | 연결 계정과 규칙은 소유자가 설정한다. PC는 격리나 승인 방화벽이 아니며 파일·명령에 OS 사용자 권한이 적용된다. 컨테이너는 Work별 필요할 때만 생성하고 PC로 자동 대체하지 않는다. PR·메일 답글 정책은 브라우저·셸까지 통제하지 않는다. 검증·설치 증거는 [로컬 운영](local-operations.md)에 기록한다. |

소스 시험이나 임시 루트의 실제 모델 시험은 설치판과 실물 기기 수용을 대신하지 않는다.
